# EuEinvoice 1.0.0

European invoice foundation extracted from Facturx: a framework-independent core and client, CII/PDF adapters, French Factur-X specifications, optional Schematron validation and official Rails integration.

This release supports Factur-X 1.09.2 / ZUGFeRD 2.5.2. UBL, Peppol, remote discovery and transport are not included. Historical Facturx APIs are not aliased.

See the README for explicit pack/policy configuration and structural versus full validation. See the architecture guide for processing limits and migration boundaries.
