# eu-einvoice-fr

Factur-X 1.09.2 / ZUGFeRD 2.5.2 specifications for MINIMUM, BASIC WL, BASIC, EN 16931 and EXTENDED. Require `eu_einvoice/fr`, create `EuEinvoice::France::Pack`, and configure a central `EuEinvoice::Client`.

The package includes profile-specific XSD resources and French addressing helpers. Full Schematron validation requires the optional `eu-einvoice-validation-fr` companion. Address validation does not establish an active destination or perform remote lookup.
