# eu-einvoice

Immutable European invoice objects, specifications, resolution and client orchestration. This package loads no XML, PDF or Rails libraries.

Require `eu_einvoice`. Install a document pack such as `eu-einvoice-fr` to configure a usable client. Country packs supply actual implementations; the core never selects a latest version or downloads artifacts.

See the [project documentation](https://github.com/AdVitam/facturx/blob/master/DOCUMENTATION.md) and [architecture](https://github.com/AdVitam/facturx/blob/master/docs/architecture/README.md).
