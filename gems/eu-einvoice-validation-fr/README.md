# eu-einvoice-validation-fr

Optional official Factur-X Schematron validation with SaxonC-HE 12.10+. Require `eu_einvoice/validation/fr`; the client selects validation explicitly and existing clients never change on require.

Configure `EU_EINVOICE_SAXONC_TRANSFORM` when Transform is not on PATH. Rules and code lists are bundled with provenance and checksums. The external engine is not distributed with this package.
